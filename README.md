# CS 340 Portfolio Reflection

## How do you write programs that are maintainable, readable, and adaptable?

I write programs that are easy to understand by keeping my code organized and simple. In Project One, I created a CRUD Python module that connected my database to the dashboard in Project Two. This made things easier because I could reuse my code instead of writing it again. I could also use this module in future projects that need to manage data.

## How do you approach a problem as a computer scientist?

I start by understanding what the client needs and breaking the problem into smaller steps. For Grazioso Salvare, I had to organize animal shelter data and display it on a dashboard. This project was different because I had to connect multiple parts of a program together. In the future, I would continue testing each part to make sure everything works correctly.

## What do computer scientists do, and why does it matter?

Computer scientists create programs that help people solve problems and work more efficiently. My dashboard helps Grazioso Salvare search and filter animal records to find dogs that could be trained for rescue work. This saves time and makes it easier to find the right animals. Projects like this show how technology can help businesses make better decisions.
